This static page is served by Nginx on an Ubuntu VM in Azure. A successful response confirms that this HTTP path returned this page; it does not by itself verify DNS, HTTPS, monitoring, or every dependency.

Project objective

Build a repeatable web environment, introduce controlled failures, and investigate them using evidence rather than assumptions.

Lab stack

  • Azure networking and Network Security Groups
  • Ubuntu Linux and Nginx
  • Terraform for infrastructure
  • Ansible for host configuration

Investigation areas

Service and startup failures, Linux permissions, network filtering, DNS and TLS, resource pressure, and log analysis. Monitoring scenarios will be added in a later phase.

Support workflow

Define expected behavior. Capture actual behavior. Establish scope. Collect evidence. Test a hypothesis. Confirm the root cause. Verify recovery and document prevention.
